Requests are grouped into windows of consecutive requests per client and scored by an Isolation Forest trained on normal synthetic traffic, alongside static threshold rules.

How to read this page. Synthetic label = what the traffic generator intended (ground truth, synthetic traffic only). Verdict = what the model decided. Triage = an analyst's decision. An anomaly score is not proof of an attack; only triage marks an event as confirmed. All traffic here is generated locally against the demo dataset.

Adaptive consistency

Simulation. The latency and staleness figures on this page come from a Monte-Carlo model of a three-region, three-replica quorum store (assumed RTTs, jitter and read delay). They are not measurements of a live multi-region database. The live controller's chosen level is applied to Cassandra statements and recorded as advisory for Redis/MongoDB.
